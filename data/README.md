# data/


**Licence of the derived files.** The datasets derived here (normalised tables, layered non-lipids, artificial sets)
are released under CC BY 4.0; each source database keeps its own licence, listed below.
This folder is **not versioned** (see `.gitignore`): it weighs several GB and the sources have
different licences. Everything is regenerated by the scripts in `scripts/` in the order given in
the root `README.md`.

**How to get the data.** `MANIFEST.csv` lists every primary source with its URL, licence, size and SHA-256 of the exact
file used in the paper. Run `bash data/download_data.sh`: it downloads the sources that have a stable public URL, tells you
which ones must be fetched by hand (LIPID MAPS extended, COCONUT, RefMet, MassBank, MoNA) and checks every file against the
manifest. A "DIFFERENT" line means the source was updated after the paper's version.
